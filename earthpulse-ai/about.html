About the project

What EarthPulse AI actually does

EarthPulse AI is a hackathon MVP that lets you pick any location on Earth and see NASA-sourced climate and fire-activity observations, a historical trend view, and an AI-written explanation of what those numbers show. It is built to make one thing clear at every step: which parts of the screen are real NASA data, which parts are calculated from that data, and which parts are AI commentary.

NASA POWER API NASA FIRMS API Supabase (DB · Auth · Edge Functions) Leaflet.js Chart.js

Data sources

  • NASA POWER (Prediction of Worldwide Energy Resources) supplies daily surface temperature, precipitation and solar radiation, derived from NASA satellite and reanalysis data, for any latitude/longitude back several decades.
  • NASA FIRMS (Fire Information for Resource Management System) supplies near-real-time active-fire detections from MODIS and VIIRS satellite instruments.

How the AI insight works

When you request an AI Earth Insight, the dashboard sends only the already-calculated, on-screen metrics (never raw satellite files, and never anything the AI could misread) to a Supabase Edge Function, which forwards a tightly-scoped prompt to the AI. The model is instructed to:

  • explain the observed trend in plain language;
  • cite the specific metrics it was given;
  • separate what was observed from what might explain it;
  • never invent a NASA measurement that wasn't supplied;
  • attach a confidence level and a "Data evidence" section.

Every insight has a View Evidence button that jumps to the exact chart or card the AI referenced, so you can check its reasoning against the source numbers yourself.

Demo mode

If NASA API access, Supabase credentials, or the AI key are not configured, EarthPulse AI runs in a clearly labelled DEMO MODE using realistic sample data shaped like real API responses. Demo data is always marked with a visible banner — it is never presented as live NASA data.

What's real vs. simulated in this build

  • Live when configured: NASA POWER climate values, NASA FIRMS fire detections, AI-generated insight text, saved locations (requires sign-in).
  • Always computed client/server-side, never invented: percentage change, trend direction, and historical comparisons — derived directly from the fetched NASA values.
  • Demo fallback only: sample climate/fire figures shown when an API or key is unavailable, always labelled "DEMO DATA."

Not affiliated with NASA

EarthPulse AI is an independent hackathon project that consumes public NASA APIs. It does not use NASA logos, insignia, or branding, and is not endorsed by NASA.
