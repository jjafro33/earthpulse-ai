// Dashboard Capabilities

Mission-console tools for one location at a time.

Every card on the dashboard traces back to a NASA measurement — nothing is estimated without being labelled as such.

Interactive Location Map

Search, drop a pin, or click anywhere on the Leaflet map to pull observations for that exact latitude/longitude.

Temperature, Rain & Solar

Daily and historical NASA POWER records for surface temperature, precipitation and solar radiation.

Active Fire Detection

Nearby fire activity from NASA FIRMS satellite hotspot detections, normalized to the selected radius.

Earth Time Machine

Compare two date ranges for the same location and see percentage change across every metric.

AI Earth Insight

A written explanation of what changed and why it might matter — grounded only in the metrics actually shown to you.

Evidence Mode

Every AI insight ships with a “View Evidence” button linking straight to the chart or number it references.

// Request Lifecycle

How a query reaches you.

01

Select a location

Search a place name or drop a pin on the map to set latitude and longitude.

02

Edge Function fetch

Supabase Edge Functions call NASA POWER and FIRMS server-side, keeping keys private.

03

Cache & normalize

Responses are cached in Postgres and shaped into clean JSON for the dashboard.

04

AI explanation

Only the calculated metrics are sent to the AI, which must cite them and show confidence.
